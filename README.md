# Mi Plato - Control de Calorias

Aplicacion web personal (PWA) para el registro diario de calorias, agua, peso, sueno, pasos y rutinas de ejercicio.

- Un solo archivo: index.html
- Funciona sin internet y guarda los datos en el navegador
- Sincronizacion opcional con Supabase (cuenta propia)
- Version actual: v8.6
